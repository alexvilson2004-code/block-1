# Сумма отрицательных элементов массива

Консольная программа на Python. Создаёт одномерный массив `A` и вычисляет
сумму отрицательных элементов, находящихся между максимальным и минимальным
элементами массива.

Максимальный и минимальный элементы в сумму не включаются. Если экстремум
встречается несколько раз, используется его первое вхождение.

## Требования

- Python 3.9 или новее

Дополнительные библиотеки не нужны.

## Запуск

```bash
python main.py
```

Пример:

```text
Введите размер массива N: 7
Введите 7 целых чисел через пробел: 5 -2 3 -4 1 8 -6
Массив A: [5, -2, 3, -4, 1, 8, -6]
Сумма отрицательных элементов между max и min: -2
```

В примере максимум `8` находится перед минимумом `-6`. Между ними расположены
элементы `-6`? Нет: крайние элементы не включаются, поэтому учитываются только
элементы между их индексами. Программа суммирует отрицательные элементы этого
участка.
